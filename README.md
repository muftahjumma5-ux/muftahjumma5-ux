
# مفتاح جمعة الفضلي | Muftah Jumaa Al-Fadli

### Software • AI • Digital Transformation • Agentic Systems

أنا **مفتاح جمعة الفضلي**، خريج **إدارة الأعمال – جامعة بنغازي**، ومهتم بتطوير البرمجيات، والذكاء الاصطناعي، وهندسة الأنظمة الرقمية، وبناء المنتجات والمنصات التقنية.

أطوّر مهاراتي التقنية من خلال بناء مشاريع حقيقية واستكشاف التقنيات الحديثة، مع التركيز على **التعلم المستمر، جودة الأنظمة، والتطوير المنهجي**.
